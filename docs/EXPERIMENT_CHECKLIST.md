## 论文中的研究二设计缺口

论文引言承诺对法律解释、规范选择、事实证明、法律归类、抗辩或例外等疑难机制进行独立研究。目前SUP-5只有难度分层分析，不足以构成独立的研究二。需要补充：

- 不读取模型表现和裁判结果的方法中立选案规则；
- 可以复核的疑难机制分类标准；
- 各机制的固定纳入规则或样本配额；
- 研究二内部比较的模型条件；
- 各疑难机制对应的假设和错误编码。

不能因为T1表现好或某个baseline失败而选择疑难案件。

## 论文中的研究三设计缺口

论文引言承诺同时检验真实新增信息和错误结果建议，但SUP-3只操纵候选结果。应增加预注册的2×2实验：

| 因素 | 水平0 | 水平1 |
| --- | --- | --- |
| 具有法律相关性的真实新增信息 | 无 | 有 |
| 缺乏材料支持的结果建议 | 无 | 有 |

主要指标包括：合理更新率、拒绝错误建议能力、事实或法源漂移，以及结果与理由一致性。在补充这一实验前，论文中的研究三主张没有得到完整实验支持。

- 在查看测试结果前确定请求级结果的非劣效界值。

- 所有条件使用相同案件，因此采用案件内配对分析。
- D1-D6分析应考虑案件和评审者的聚类或随机效应。
- 明确D4及救济相关D5项目的N/A与缺失值处理。
- 根据开发集完成功效分析，不能只按API预算选择正式样本量。
