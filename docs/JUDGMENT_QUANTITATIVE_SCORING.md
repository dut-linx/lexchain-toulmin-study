# 判决结果确定性量化评分

该评分器不调用API，直接将模型输出与通过QC的参考答案对齐，满分100分：诉请识别20分、结果分类20分、支持金额25分、裁判操作10分、付款总额15分、付款关系10分。

诉请先根据项目名称、请求原文、诉请类型和请求金额做一对一匹配，再计算诉请数量的F1。未匹配诉请在后续结果、金额和操作指标中按错误处理。金额相似度为 `max(0, 1-|预测值-标准值|/max(|标准值|,100))`；完全一致另行报告 exact rate，避免只看连续相似度掩盖错误。付款关系逐项比较付款人、收款人、责任方式、金额和关联诉请，各占该义务相似度的五分之一。

总分公式为：`20×诉请F1 + 20×结果准确率 + 25×支持金额相似度 + 10×裁判操作准确率 + 15×付款总额指标 + 10×付款关系相似度`。其中付款总额指标由是否存在付款与总金额相似度各占一半。
